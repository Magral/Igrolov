# Изменения в Игролов 1.2.4

- Добавлена загрузка следующих страниц для популярных новинок и лидеров со скидкой по кнопке.
- Бесплатные игры исключены из подборок и из скидочного фильтра.
- В карточках лидеров добавлены миниатюры Steam.
- Кнопка «Подробнее» открывает крупное изображение и описание игры из Steam.
- Добавлены тесты пагинации, RU-данных игры и исключения бесплатных игр.
