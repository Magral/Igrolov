# Изменения в Игролов 1.2.5

- Карточки поиска уплотнены: второстепенные строки занимают меньше места, длинный текст ограничен по числу строк.
- Четыре действия в предложении оформлены контурными компактными кнопками.
- Для игр без RU-страницы изображения и описание запрашиваются из глобальной карточки Steam.
- Глобальные данные не меняют цену, скидку и статус доступности Steam RU.
- Добавлен регрессионный тест, проверяющий сохранение RU-статуса при получении глобальных материалов.
