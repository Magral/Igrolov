# Игролов 1.2.1

- В карточках вкладки «Лидеры продаж» добавлена проверка минимальной цены Plati и GGSEL для выбранной Steam-игры.
- Проверка запускается по запросу пользователя и не отправляет десятки фоновых запросов при открытии списка.
- В список цен попадают только подтверждённые предложения Gift/Key для основной игры, с проверенными наличием и ценой, и с подтверждённым регионом RU.
- При временном сбое площадки в карточке остаётся последняя подтверждённая цена.
- Добавлены unit-тесты отбора минимальных цен и UI-проверки фильтров вкладки лидеров.
