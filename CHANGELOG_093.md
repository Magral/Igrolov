# 0.9.3-stable (база 0.9.1)

- Сохранён дизайн и быстрый поиск 0.9.1.
- Единая проверка предложений для поиска и мониторинга: только заголовки, регион РФ, тип и Steam-справочник.
- Steam-справочник загружается отдельно от каталога, кэшируется 7 дней; максимум три названия DLC из Steam API для ограничения задержки.
- Premium/Deluxe/Ultimate/Gold/Complete Edition остаются полноценными изданиями. Premium Add-ons, VIP Membership, Car Pass и другие дополнения исключаются.
- Никаких запросов к отдельным карточкам Plati для поиска/мониторинга.

Ограничения: фильтрация РФ по заголовку не подтверждает реальную доступность или наличие. Steam API может не содержать все DLC. Полная сборка Android SDK в этой среде не выполнялась.
