# Игролов 1.1.4

- Подключён публичный каталог покупательских предложений GGSEL; Seller API и ключ продавца не используются.
- Поиск GGSEL включён в общий поиск по выбранной Steam-игре и сохранённым алиасам.
- Результат показывает источник, ссылку на карточку и цену за одну копию в RUB; добавлен фильтр «Все / Plati / GGSEL».
- Каталоговые DLC, аккаунты, аренда, предзаказы, карточки с вариантами, неактивный статус, неизвестный Steam Gift/Key и товары без цены отбрасываются.
- Результаты Plati остаются единственным источником автоматического мониторинга в этой версии; wishlist-цена Plati не подменяется ценой другого маркета.
- Добавлены unit-регрессии по форме GGSEL API, основной игре, DLC, аккаунтам, наличию, региону и цене.
