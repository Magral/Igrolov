# Игролов 1.6.0

## Новое
- В «Лидерах» появился динамический раздел «Фесты» с играми из актуальных тематических распродаж Steam.
- Для найденных игр показываются скидка и цена Steam RU; в карточке указано название распродажи.
- В разделе работают фильтры, миниатюры, отзывы, поиск предложений Plati/GGSEL, кнопка «Подробнее» и добавление в мониторинг.
- Бесплатные игры в тематических распродажах не показываются.

## Оптимизация
- Проверенные данные Steam для карточек «Лидеров» сохраняются на 5 минут. Это сокращает повторные запросы при переключении разделов.
- Неизвестный региональный статус не считается подтверждённым и не кэшируется.
