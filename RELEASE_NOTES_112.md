# Игролов 1.1.2 — поиск ZERO PARADES

Исправлен поиск ZERO PARADES: Director's Cut. Steam использует обновлённое название игры, но карточки продавцов Digiseller/Plati по-прежнему находятся под названием ZERO PARADES: For Dead Spies. По AppID Steam приложение теперь запрашивает каталог под исходным названием, при этом фильтры наличия, способа передачи, состава и цены остаются прежними.

Версия: `1.1.2`, `versionCode=119`.
