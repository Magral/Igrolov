# Игролов 1.0.6.1 — исправление цены отслеживаемого товара

Android-приложение для поиска Steam-игр на Plati, фильтрации Gift/Key, отслеживания товаров и ценовых уведомлений. Мониторинг развивается вместе с поиском.

## Исправление 1.0.6.1

При добавлении товара из поиска сохраняются каноническое название игры, Steam AppID и проверенная цена. Повторный расчёт издания использует название выбранной игры, а не полный заголовок товара. Контекст сохраняется после перезапуска и передаётся также из предложений мониторинга.

Старые карточки восстанавливают контекст по однозначному известному названию. Сетевая ошибка оставляет последнюю проверенную цену с отметкой отсутствия связи; отсутствие товара или неподтверждённый вариант не подменяются актуальной ценой. Подробности: [RELEASE_NOTES_1061.md](RELEASE_NOTES_1061.md).

## Проверка предложений

Поиск и мониторинг используют общую проверку свежей карточки: название, тип передачи, состав, РФ, наличие и цена. Категории сопоставляются по продавцу и ID, включая вложенные категории. Steam сам по себе не означает Gift. Аккаунты, аренда, оффлайн-доступ и услуги смены региона исключаются; противоречивый тип остаётся неподтверждённым. Подробности категорий: [DIGISELLER_CATEGORIES_104.md](DIGISELLER_CATEGORIES_104.md).

При выборе РФ/издания цена запрашивается через Digiseller price/calc. Неопределённые варианты скрываются из проверенной выдачи. После проверки всех кандидатов в выбранной глубине каталога предложения сортируются по свежей цене. Запросы карточек выполняются в фоне, до четырёх одновременно на проверку. Сетевой сбой прерывает пакет мониторинга, сохраняя предыдущий результат.

Наличие и цена подтверждаются на момент ответа API. Данные продавцов могут быть неточными, а условия и комиссии другого способа оплаты — отличаться. Приложение не оформляет покупки.

## Поиск

Подсказки учитывают опечатки, известные русские названия и сокращения, а также неправильную раскладку. Выбор точной игры сохраняет Steam AppID; Steam appdetails подтверждает основную игру. Неизвестный суффикс не считается основной игрой, а общее «Standard» не доказывает принадлежность к выбранной игре.

Фильтры Gift/Key, состава, подтверждённой РФ и предельной цены сохраняются между запусками. Можно раскрыть причины скрытия карточек. Результаты показываются по 30, устаревший поиск отменяется при изменении запроса.

## Мониторинг

Для автоматических уведомлений нужны подтверждённые основная игра, Gift/Key, РФ, наличие и цена. Проверка не ограничена первыми 20 кандидатами. Три минимальных предложения выбираются после расчёта цен всех кандидатов.

Уведомления приходят о новых предложениях до вашей цели и дальнейшем снижении уже найденной цены. Одинаковая цена и возврат к ранее сообщённой цене не создают повтор. Старые записи уведомлений мигрируют без массовой повторной рассылки.

Проверки запрашиваются примерно раз в час при наличии сети; Android может задерживать фоновые задачи. Ручная проверка не отменяет уже запущенную. Ошибки Steam/API отображаются отдельно: прежний минимум и история сохраняются, новые уведомления не создаются. Добавление/удаление отслеживаний не блокируется сетевыми запросами; устаревший результат не восстанавливает удалённую или изменённую запись.

История хранит минимумы за 90 дней, до 400 успешных проверок. При отсутствии подтверждённого предложения записывается пропуск; график не соединяет точки через такой пропуск и не подменяет его нулём. Отслеживаемые напрямую карточки также проверяют вариант; старый кэш стартовых цен перепроверяется.
