# Игролов 1.0.4 — кандидат, не релиз

**Статус: разработка продолжается.** GitHub Actions собирает отладочный APK, но успешная компиляция не подтверждает завершение плана. Условия выпуска: [RELEASE_104_CHECKLIST.md](RELEASE_104_CHECKLIST.md).

## Реализовано в кандидате 1.0.4

- Повторные попытки временных сетевых ошибок Digiseller.
- Защита от устаревшего поиска, ограничение числа потоков и вывод предложений по 30.
- Мониторинг проверяет до 20 дешёвых предложений, останавливаясь после трёх подтверждённых доступных товаров. Проверка `is_available` не гарантирует доступность конкретного варианта.
- Для товаров с выбором региона мониторинг не использует неподтверждённую базовую цену для уведомлений; возможны пропущенные уведомления.
- Закреплена единая **тестовая** подпись Debug APK. Это не производственный ключ: при переходе со старой подписи требуется однократная переустановка.

## Ещё не реализовано / не проверено

- Категории Gift/Key на уровне API Digiseller: исследование в [DIGISELLER_CATEGORIES_104.md](DIGISELLER_CATEGORIES_104.md). Сейчас фильтрация по названию и Steam-справочнику; полноценная серверная классификация не подтверждена.
- Точная цена и наличие товара при выборе России в параметрах покупки.
- Полное тестирование поиска, фильтров, уведомлений, обновления APK и устойчивости сети на телефоне.

## Сборка кандидата

Откройте [GitHub Actions](https://github.com/Magral/Igrolov/actions), выберите последний успешный запуск и скачайте ZIP из раздела **Artifacts**; извлеките Debug APK. Сборки из закреплённого debug-ключа обновляют друг друга при увеличении `versionCode`, но не совместимы с прежними случайными debug-подписями и релизной подписью. Не используйте публичный тестовый ключ для релизной публикации.

## История: 1.0.3

Приложение для поиска предложений Steam-игр на Plati и отслеживания цен. Поддерживает поиск, фильтр региона РФ, исключение дополнений и уведомления о подходящих предложениях.

## Что изменилось в 1.0.3

- Настройки перенесены под значок шестерёнки в правом верхнем углу, без подписи.
- Четвёртая вкладка теперь называется «Лидеры продаж».
- Загружается до 100 популярных платных игр из поиска магазина Steam с сортировкой Top Sellers и фильтром бесплатных игр. Это **не точная копия** отдельного чарта выручки Steam Charts.
- При нажатии на название игра переносится в поле поиска первой вкладки. Поиск на Plati запускается отдельной кнопкой.
- Кнопка «Обновить» повторно запрашивает список. Если Steam недоступен, выводится сообщение.
- Все прежние настройки, справочник Steam и правила DLC сохранены.

**Ограничения нового списка:** Steam может изменять формат выдачи или ограничивать запросы; тогда список может быть короче 100 или не загрузиться. Фильтр бесплатных игр запрашивается у Steam; дополнительная независимая проверка цены каждой игры пока не реализована. Перед распространением проверьте на смартфоне, что бесплатные игры действительно отсутствуют.

## Что изменилось в 1.0.2

- Исправлен справочник Steam: выбранная игра открывается по точному Steam ID, а не по повторному поиску названия.
- Исправлена загрузка списка DLC. Приложение запрашивает данные основной игры целиком и отдельно получает названия дополнений.
- Если Steam временно не отдаёт часть DLC, справочник показывает это в сообщении, а неполный список не сохраняется в кэш.
- Старый кэш Steam обновляется автоматически. Сохранённые игры и правила не удаляются.

## Как проверить

Нажмите шестерёнку справа сверху, затем откройте «Справочник игр и правила DLC». Введите название игры, нажмите «Найти название в Steam», выберите основную игру и нажмите «Открыть / обновить из Steam». Проверьте число DLC и список. Если Steam сообщает о недоступных DLC, повторите позже.

## Сборка и установка

Откройте папку `Igrolov` в Android Studio и дождитесь синхронизации Gradle. Соберите APK и подпишите его **тем же постоянным JKS**, которым подписана версия 1.0.1, чтобы обновить приложение без удаления данных. Ключ и пароли в архив не входят. Для Google Play потребуется подписанный AAB.

**Ограничения:** Steam может ограничивать частоту запросов, поэтому для игр с большим количеством DLC обновление справочника занимает время. Региональная совместимость товаров определяется по доступным данным и не гарантируется. Фоновая проверка может запускаться с задержкой Android.

**Статус:** исходный код подготовлен, сборка и работа на устройстве в этой среде не проверены.


## Сборка 1.0.2 (исправление Lint)

Временно отключена обязательная проверка Lint для release-сборки: на текущей установке Android Studio она падает при завершении сервиса Lint. Это обход ошибки сборки, не проверка безопасности и не исправление Lint. Перед публикацией в Google Play необходимо восстановить проверку и устранить исходный сбой.

Для подписания используйте меню Android Studio Build → Generate Signed App Bundle or APK → APK и существующий ключ .jks (не создавайте новый).


Исправление сборки 1.0.3: кнопка настроек использует символ шестерёнки без зависимости от Compose Icons; устранены ошибки Unresolved reference Close/Settings.
