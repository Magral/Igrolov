# Игролов 1.1.6

Android-приложение для поиска предложений Steam-игр на Plati и GGSEL, сравнения цен, списков желаний и ценового мониторинга.

В 1.1.6 исправлены маршруты публичного каталога GGSEL: поиск и мониторинг используют его API для категорий и предложений. Общая проверка по-прежнему отбрасывает аккаунты, DLC, неподтверждённые регионы и недоступные товары. В 1.1.5 добавлена поддержка GGSEL в мониторинге, сохранение источника и прямой ссылки, а также защита предыдущей истории при ошибке источника.

Релиз 1.1.6 готовится. Стабильный релиз: [Игролов 1.1.5](https://github.com/Magral/Igrolov/releases/tag/v1.1.5).

## Поиск

Название Steam и AppID остаются основной точкой поиска; при отсутствии подтверждённых товаров приложение может предложить альтернативное название продавца, которое пользователь подтверждает и сохраняет по AppID. Предложения проверяются по типу Gift/Key, составу, доступности, РФ и актуальной цене.

## Мониторинг

Проверка выполняется примерно раз в час по Plati и GGSEL. В результаты и уведомления включаются активные предложения основной игры с указанным регионом РФ и подтверждённой ценой. Карточки показывают источник, уведомления и журнал открывают прямую ссылку на нужную площадку. Индивидуальное отслеживание товара и минимальная цена списка желаний пока используют Plati.

## Установка и ограничения

Стабильные APK публикуются в приватном [GitHub Releases](https://github.com/Magral/Igrolov/releases). Это прямой APK, не публикация в Google Play. Для обновления предыдущей установки сохраняется подпись приложения.

Для сборки требуются JDK 17, Android SDK 35 и Gradle 8.9: `gradle :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest`.

Steam wishlist и цены получаются через публичные Steam endpoints. Steam может изменить формат или доступность этих endpoints. Импорт работает с открытыми профилями и не запрашивает вход, пароль или ключ API.
