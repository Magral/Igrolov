# Игролов 1.0.5 — проверенный кандидат

Поиск предлагает точную игру Steam с AppID, учитывает опечатки, известные русские названия, сокращения и неверную раскладку. Gift/Key, состав, подтверждённая РФ и предельная цена сохраняются между запусками. Под результатами можно раскрыть причины скрытия предложений.

Проверки расширены полными страницами Civilization VI, Cities: Skylines и The Sims 4. Выбор подсказки проверяется через Steam appdetails: DLC нельзя использовать вместо основной игры. Неизвестные суффиксы и номера других частей серии не считаются подтверждением основной игры. Проверки наличия и цены из 1.0.4.1 сохранены; мониторинг цен не изменяется.

48 JVM-тестов и 7 Android-проверок прошли. Статус проверок и объём версии: [RELEASE_105_CHECKLIST.md](RELEASE_105_CHECKLIST.md). Текущий стабильный APK: [1.0.4.1](https://github.com/Magral/Igrolov/releases/tag/v1.0.4.1). Начало разработки 1.0.5 не публикует стабильный Release автоматически.

## История 1.0.4

Игролов 1.0.4

Android-приложение для поиска Steam-игр на Plati, фильтрации Gift/Key, работы со справочником Steam и отслеживания цен.

## Поиск и категории

Проверяется каждая найденная карточка, а не первые 12. Запросы выполняются в фоне, не более четырёх одновременно. Категория сопоставляется по продавцу и ID категории, включая вложенные категории. Категории разных продавцов не смешиваются.

Если продавец не задал категорию, способ передачи определяется по явным указаниям в названии и описании товара. Steam сам по себе не означает Gift. При противоречии данных показывается «Не указан». Аккаунты, аренда, оффлайн-доступ и услуги смены региона исключаются по доступным данным карточки. Источник определения виден под предложением; при ошибке загрузки карточки способ передачи остаётся неподтверждённым.

В публичном `search2` нет документированного параметра фильтрации Gift/Key. Поэтому реализован клиентский вариант на реальных карточках и категориях продавцов; неизвестные числовые категории не интерпретируются. Подробности: [DIGISELLER_CATEGORIES_104.md](DIGISELLER_CATEGORIES_104.md).

Выдача сортируется по цене, показывается по 30 предложений. Основные игры и DLC дополнительно разделяются по справочнику Steam и пользовательским правилам. Устаревший поиск отменяется при изменении запроса.

## Регион и цена

Явно исключённая РФ скрывается. Неподтверждённый регион отмечается отдельно. Для карточек с параметрами цена обозначается как зависящая от варианта. Приложение не оформляет покупку и не обещает окончательную цену выбранной страны с комиссиями: её необходимо проверить на стороне продавца. Названия, описания и категории задаются продавцами и могут быть неточными.

## Установка

APK версии 1.0.4 прикреплён к [GitHub Release v1.0.4](https://github.com/Magral/Igrolov/releases/tag/v1.0.4). `versionCode=107`. Подпись — тот же закреплённый debug-ключ, что у предыдущих сборок из этого репозитория. Автоматическая проверка устанавливает предыдущий APK, сохраняет данные, затем обновляет приложение и проверяет сохранность.

Это APK для прямой установки из приватного репозитория, не публикация в Google Play. Закреплённый debug-ключ открыт в исходниках и не является production-ключом. APK с другой подписью не обновляется поверх существующей установки.

## Проверки

GitHub Actions запускает JVM-тесты, собирает приложение и instrumentation APK, проверяет интерфейс и обновление на Android-эмуляторе. Мониторинг цен в завершающих изменениях 1.0.4 не изменён; добавлен тест существующего worker: пять недоступных предложений, доступное шестое, уведомления, отсутствие повторов и повторная попытка при сетевой ошибке.

Проверки на эмуляторе не означают проверку всех моделей телефонов или всех предложений площадки. Изменения API и ошибки продавцов обрабатываются без выдумывания подтверждённого типа/региона.

## Сборка

JDK 17, Android SDK 35, Gradle 8.9. Восстановите `signing/igrolov-debug.jks` из base64-файла в той же папке. Команды: `gradle :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest`. Проверки и APK доступны также в [GitHub Actions](https://github.com/Magral/Igrolov/actions).
