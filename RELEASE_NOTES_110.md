# Игролов 1.1.0 — профили Steam и цены списка желаемого

Вкладка «Желания» теперь поддерживает несколько сохранённых открытых профилей Steam. Приложение получает отображаемое имя профиля Steam, сохраняет список локально и позволяет переключаться между профилями или удалять закладки. Для добавления друга вставьте его SteamID64 или ссылку на открытый профиль; загрузка и обновление запускаются вручную.

В карточке игры отображаются название, Steam AppID, цена Steam для региона RU и текущая скидка. Если действует скидка, рядом видна прежняя цена. Бесплатные игры помечаются отдельно.

Кнопка «Искать Plati» переводит выбранную игру в существующий экран поиска. Поиск всё так же запускается отдельным нажатием на «Искать на Plati» с действующими фильтрами. После поиска подтверждённая минимальная цена сохраняется в строке игры и выбранном профиле. Повторное обновление списка Steam сохраняет ранее найденный минимум.

Вход в Steam, пароль и ключ API не требуются. Список доступен только для открытого профиля. Если Steam не отдаёт название или цену для конкретного AppID, приложение показывает состояние «Название игры не получено» или «Нет цены RU».

Проверка кандидата: 71 JVM-тест и 16 Android-сценариев на каждом из API 26 и 29 прошли. В logcat нет FATAL EXCEPTION. GitHub Actions: [run 39597223321, попытка 2](https://github.com/Magral/Igrolov/actions/runs/39597223321). Версия сборки: versionCode 117, versionName 1.1.0.

Публикация стабильного APK запускается отдельным release-коммитом после прохождения полного CI.
