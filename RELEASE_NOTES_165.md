# Игролов 1.6.5

- Из пользовательских экранов убраны технические сведения о сетевых запросах, источниках и причинах отказа.
- Вместо подробных ошибок приложение показывает короткие понятные сообщения.
- При неудачном обновлении сохраняется последняя подтверждённая цена.
- Проверены установка и обновление приложения, поиск игры, мониторинг и отображение цены.

Проверки: 190 unit-тестов, Debug APK, instrumentation APK, live smoke, UI-сценарии на Android 26 и 29.
