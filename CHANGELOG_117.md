# Игролов 1.1.7

- Добавлено индивидуальное отслеживание товаров Plati и GGSEL из результатов поиска и карточек мониторинга.
- Источник, ID, прямая ссылка, название игры и проверенная цена сохраняются раздельно для разных площадок; прежние числовые ключи читаются как Plati.
- Цены индивидуально отслеживаемых товаров обновляются с повторной проверкой наличия и цены; GGSEL-товары ищутся по подтверждённой Steam-игре и точному ID предложения.
- Минимальные цены Plati и GGSEL сохраняются отдельно в профилях wishlist и отображаются рядом с ценой Steam RU.
- Регрессионные тесты проверяют раздельные ключи кэша, совместимость старых записей и UI-добавление/обновление товара.
