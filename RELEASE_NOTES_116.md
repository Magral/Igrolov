# Игролов 1.1.6

Исправлена ошибка HTTP 404 при поиске на GGSEL. Категория игры выбирается по точному названию; её `digi_catalog` читается из встроенных данных страницы категории, затем предложения загружаются отдельным публичным маршрутом. Так обработан ответ поиска категорий, в котором есть имя и slug, но нет ID. Исправление применяется и к обычному поиску, и к мониторингу цен.

Перед публикацией GitHub Actions проверяет живую цепочку поиска категории, получения ID со страницы и загрузки товаров, а также собирает APK и прогоняет тесты на Android API 26 и 29.
