# Игролов 1.1.6

Исправлен поиск GGSEL, который в 1.1.4 завершался сообщением HTTP 404. Поиск категорий и загрузка предложений используют отдельные публичные маршруты. Категория принимается только при точном совпадении игры; ID каталога сверяется со страницей GGSEL. Если каталог возвращает пустой список либо старый host отвечает DNS/HTTP 4xx ошибкой, приложение использует публичный query endpoint GGSEL с той же категорией и названием игры.

Все строки проходят прежние строгие проверки наличия, основной игры, Steam Gift/Key и региона. Для цены используется цена за одну штуку из `price_wmr_for_one`, а не общая цена товара; строки с `is_active=false` исключаются. DLC и аккаунты не добавляются. Проверки GGSEL общие для ручного поиска и мониторинга.

Релиз публикуется после живой проверки, что query endpoint возвращает активный Stellaris товар с ID и ценой, а также после unit-тестов, сборок APK и instrumentation APK и UI-сценариев на Android API 26 и 29.
