# Игролов 1.1.6

Исправлена ошибка HTTP 404 при поиске на GGSEL. Приложение использует отдельные публичные маршруты GGSEL для поиска категорий и получения предложений. Исправление применяется и к обычному поиску, и к мониторингу цен.

Перед публикацией GitHub Actions проверяет оба API-маршрута на живом каталоге, а также собирает APK и прогоняет тесты на Android API 26 и 29.
