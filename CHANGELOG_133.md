# Изменения в Игролов 1.3.3

- В «Лидерах» проверенные игры отображаются партиями по 10, пока догружается остальная часть рейтинга.
- Подразделы «Популярные новинки» и «Топ продаж со скидками» обновляют список по мере проверки, сохраняя пагинацию.
- Загрузка миниатюр переведена на Coil: запросы отменяются при уходе карточки с экрана, изображения используют дисковый и оперативный кэш.
- Если основной адрес обложки не отвечает, приложение получает запасной адрес из Steam appdetails и сохраняет его для следующего показа.
