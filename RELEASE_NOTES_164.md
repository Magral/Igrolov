# Игролов 1.6.4

- Проверки цен в «Лидерах» по разным играм выполняются независимо; медленный запрос одной игры не блокирует запуск проверки другой.
- Повторно используются общие четыре фоновых потока для проверки региональной доступности игр и загрузки Steam-отзывов. Это убирает создание и остановку отдельных пулов на каждой порции списка и ограничивает суммарную конкуренцию этих задач.
- Временный отказ SteamDB при поиске основной игры для DLC не кэшируется на 30 дней: повторная попытка разрешается через 2 минуты.
- В настройках отображается текущая версия приложения.
- Исправлен фильтр современных вертикальных обложек Steam, который раньше отбрасывал library_capsule.jpg.

Проверки: unit-тесты, live smoke, обновление с сохранением данных и UI-сценарии Android 26 и 29.
