# Игролов 1.2.3

Вкладка «Лидеры» теперь содержит три подборки:

- **Топ продаж** — 100 популярных платных игр Steam.
- **Популярные новинки** — региональная подборка Steam для RU.
- **Топ со скидками** — игры из топа продаж с подтверждённой скидкой Steam RU.

Во всех подборках можно фильтровать игры по доступности в Steam RU, открывать поиск предложения по AppID и сравнивать подтверждённые минимальные цены Plati и GGSEL. Неопределённый статус Steam RU не считается доступностью.
