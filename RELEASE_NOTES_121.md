# Игролов 1.2.1

В лидерах Steam теперь можно прямо в карточке игры проверить минимальные цены Plati и GGSEL. Поиск запускается по кнопке и использует AppID этой игры. Показывается минимум только среди подтверждённых базовых предложений Steam Gift/Key с проверенными наличием, ценой и регионом RU; DLC и аккаунты отсекаются существующими правилами каталога.

Если площадка временно не отвечает, последняя подтверждённая цена остаётся в карточке. Вкладка также показывает Steam RU цену и скидку, AppID и фильтры доступности; неопределённый статус не считается недоступностью.

Релиз публикуется после прохождения unit-тестов, Debug APK, instrumentation APK, GGSEL live smoke и UI-сценариев на Android API 26 и 29.
