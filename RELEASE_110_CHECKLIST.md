# Игролов 1.1.0 — сохранённые профили Steam и цены желаемого

Статус: стабильный релиз 1.1.0 опубликован 21 октября 2026 года.

- [x] Сохраняются несколько открытых профилей с реальными публичными именами Steam; можно переключать и удалять профили.
- [x] Старый одиночный список SteamID64 мигрирует в закладки без потери локального списка.
- [x] Для игр разрешаются названия из Steam Store, показываются Steam RU цена, исходная цена и скидка.

- [x] 71 JVM-тест прошёл; APK и instrumentation APK собраны.

## Ограничения

Импорт и цены используют публичные Steam endpoints, часть из которых не документирована Valve. Профиль должен быть открытым. Поиск Plati выполняется вручную для выбранной игры; периодический мониторинг не менялся.
