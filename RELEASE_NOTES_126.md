# Игролов 1.2.6

В карточках «Лидеров», «Популярных новинок» и «Топа со скидками» показывается процент положительных отзывов Steam. Рядом — маленький зелёный палец вверх при значении выше 60% или красный палец вниз при значении ниже 60%. Ровно 60% показывается без значка.

Из «Лидеров» и списка желаемого можно добавить игру в мониторинг: указать желаемую цену и выбрать Gift, Key или оба типа. Уже отслеживаемые игры отмечены «В мониторинге». Уведомления и проверки используют общую систему мониторинга Plati/GGSEL для РФ.
