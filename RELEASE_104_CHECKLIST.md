## Диагностика схемы категорий (коммит 594ad2e)
- Добавлено безопасное логирование **только имён** полей первого товара `search2`, содержащих `categor`, `seller`, `owner`, `platform`; без значений, ID, запросов и названий товаров.
- Это исследовательский шаг, **не реализация фильтра категорий**. Если API не возвращает такие поля, журнал покажет пустой список.
- Для проверки: запустить поиск на устройстве и посмотреть Logcat с фильтром `IgrolovCatalog`; сопоставить полученные ключи с документированными схемами Digiseller.
- После подтверждения структуры ответа реализовать проверяемую классификацию и удалить диагностическое логирование перед выпуском.
