# Исправление 1.0.4.1: Stellaris

Повторная проверка 1.0.4 выявила существенные дефекты ручного поиска. Ранний выпускной чек-лист ниже не подтверждает качество выдачи Stellaris.

- Проверка составов выполняется до показа; неизвестные названные дополнения скрыты в фильтре «Игра».
- Нет подтверждения наличия или цены — нет товара в ценовой выдаче.
- Для выбранной РФ/основной игры используется price/calc, а не минимальная каталожная цена; после расчёта выдача пересортируется.
- Регрессия: вся записанная страница из 100 реальных результатов Stellaris, а не только несколько хороших предложений.
- Мониторинг цен остаётся неизменным.

Проверка кандидата: [GitHub Actions 39360643409](https://github.com/Magral/Igrolov/actions/runs/39360643409) — JVM, сборка, обновление 1.0.4 → 1.0.4.1, интерфейс, неизменённый worker и отдельный поиск Stellaris успешны. Получен и просмотрен снимок результата. Финальный коммит повторяет проверки перед публикацией.

Отдельный релиз исправления: [v1.0.4.1](https://github.com/Magral/Igrolov/releases/tag/v1.0.4.1). Прежний тег не перемещается.

## Зафиксированные ограничения

- Проверка выполняется на Android-эмуляторе; это не утверждение о ручном тестировании на физическом телефоне.
- Категории и описания заполняются продавцами и могут быть неполными/ошибочными. Неизвестные данные явно отмечаются.
- Приложение не оформляет покупку и не рассчитывает окончательную цену выбранной страны с комиссиями; наличие товара в целом не гарантирует наличие каждого варианта. Цена с параметрами помечается, итог проверяется на стороне продавца. Автоматический расчёт checkout не входит в этот APK.
- Это выпуск для прямой установки, не Google Play. Открытый тестовый ключ не является production-ключом. Обновление возможно поверх APK с той же подписью; переход с другой подписи без миграции невозможен.
- Мониторинг сохранён в прежнем виде, включая его консервативные ограничения по регионам, вариантам и цене. Новая ручная классификация не применяется к фоновому мониторингу.
