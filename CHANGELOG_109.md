# 1.0.9

- Добавлен ручной импорт открытого списка желаемого Steam по SteamID64 или публичной ссылке профиля.
- Импорт сохраняется локально с датой последнего обновления; ошибка Steam не удаляет сохранённый список.
- Названия игр загружаются компактными пакетами через Store API; при недоступности названия остаётся Steam AppID.
- Импорт не запускает поиск продавцов автоматически. Кнопка игры переводит её в поиск, откуда подходящий товар можно добавить в мониторинг.
- Обновлены цвета и карточки интерфейса; пять основных вкладок помещаются в компактную фиксированную панель.
- Добавлены unit- и UI-регрессии для профиля, разбора списка, кэширования и раздельного импорта/поиска.
