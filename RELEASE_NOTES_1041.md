Исправление поиска Stellaris и других игр с большим количеством DLC.

- Основная игра больше не определяется по правилу «не нашли слово DLC — значит игра». Неопознанные названные дополнения не проходят фильтр «Игра», даже при недоступности Steam.
- Классификация состава выполняется до показа результатов. Для ручного поиска используется быстрый Steam-справочник без сотен последовательных запросов DLC.
- Отсутствующие товары и карточки без подтверждённого наличия исключаются из выдачи.
- Цена каталога больше не используется как актуальная: берётся свежая цена RUB карточки либо результат Digiseller price/calc для однозначно выбранных РФ и основной игры.
- Карточки со сложным/неоднозначным выбором, непроверенным остатком варианта или неудачным расчётом цены скрываются из ценовой выдачи. Это может уменьшать число результатов.
- Сортировка выполняется после проверки актуальных цен.
- Добавлен регрессионный набор реальной страницы из 100 результатов Stellaris и проверки цен, наличия и состава.

Мониторинг цен не изменён. APK имеет versionCode 108 и прежнюю закреплённую debug-подпись, обновляется поверх 1.0.4 без удаления данных.

Цена относится к проверенному ответу API в момент поиска; остаток и условия продавца могут измениться до оплаты. Дополнительные комиссии другого способа оплаты могут отличаться.
