# Игролов 1.0.6 — мониторинг и история цен

Статус: кандидат 1.0.6 проверен. Мониторинг развивается вместе с поиском; прежнее ограничение снято пользователем.

- [x] Общая проверка карточек поиска и мониторинга: свежие название/тип/РФ, наличие, точная цена российского варианта, исключение аккаунтов и DLC.
- [x] Проверка всех кандидатов в заданной глубине каталога, сортировка по фактической цене; убрать предел в 20 карточек и последовательную загрузку сотен DLC в мониторинге.
- [x] Выбор точной игры Steam для отслеживания, сохранение AppID.
- [x] Сетевые ошибки не подменяют последний результат и не добавляют ложные точки истории; повторные попытки и требование сети.
- [x] Повторное уведомление о дальнейшем снижении цены; миграция старого списка notified без шквала повторов.
- [x] Список отслеживания не блокируется сетью; удалённые и изменённые отслеживания не восстанавливаются устаревшим ответом.
- [x] История минимумов и график с датами, разрывы при отсутствии предложений, сохранение прежних данных.
- [x] Прямые отслеживаемые карточки не показывают цену неопределённого варианта как точную.
- [x] JVM-регрессии, фактический WorkManager на Android, обновление с 1.0.5 (резервная база 1.0.4.1), UI и артефакты CI.

Следующий этап 1.0.7: Room, миграция существующей истории/отслеживаний, кэш и дальнейшая работа с графиками. Стабильная публикация 1.0.6 не запускается автоматически.
