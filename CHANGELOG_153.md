# Изменения в Игролове 1.5.3

- Исправлена загрузка портретных обложек современных Steam-игр: запрашиваются хешированные URL официальных Store assets.
- Добавлена последовательная цепочка резервных адресов; неудачные кэшированные ссылки удаляются, затем снова проверяется исходная обложка.
- В карточках уже отслеживаемых игр кнопка переименована в «Добавить издание».
- Добавлены unit-тесты разбора хешированных обложек Steam.
