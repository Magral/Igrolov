# Изменения в Игролов 1.3.2

- Миниатюры в «Лидерах» используют официальный адрес изображения из метаданных Steam, если он доступен.
- Для «Желаемого» добавлен резервный запрос картинки через Steam appdetails, когда прямой адрес не срабатывает.
- Временные ошибки загрузки повторяются; успешно полученные обложки сохраняются в локальном кэше приложения.
