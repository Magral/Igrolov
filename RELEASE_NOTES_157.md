Игролов 1.5.7 загружает вертикальные обложки SteamGridDB со страниц сайта, без API и без личного ключа. Приложение выбирает только полноразмерные постеры 600×900. Горизонтальный баннер не может попасть в портретную миниатюру.

Список результатов кэшируется на устройстве; при недоступности сайта приложение продолжит использовать сохранённую обложку и Steam-источники. Если у игры нет вертикальной обложки ни в Steam, ни в каталоге SteamGridDB, карточка останется с вертикальной заглушкой.
