# Игролов 1.1.7

Добавлено индивидуальное отслеживание конкретных товаров на Plati и GGSEL. Добавить товар в монитор можно из результатов ручного поиска или карточки найденного предложения. Для каждого товара сохраняются площадка, ссылка, название игры и история проверенной цены. Одинаковые ID на разных площадках обрабатываются как разные позиции. Старые числовые записи продолжают работать как товары Plati.

При обновлении Plati повторно проверяются карточка товара, игра, наличие и цена выбранного варианта. GGSEL-предложение повторно ищется по сохранённой игре Steam и точному ID, поэтому монитор обновляет тот же товар, а не соседнее предложение.

В списке желаний Steam отображаются отдельные минимальные цены Plati и GGSEL. Они сохраняются рядом с ценой и скидкой Steam RU; нажатие на игру открывает её поиск предложений.

Релиз публикуется после live smoke GGSEL, unit-тестов, сборки Debug APK и instrumentation APK, а также UI-сценариев обновления на Android API 26 и 29.
