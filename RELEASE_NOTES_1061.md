# Игролов 1.0.6.1 — цена товара после добавления из поиска

Статус: проверка исправления.

Исправлен воспроизводимый случай: в поиске вариант издания рассчитывался по каноническому названию игры, а после добавления в «Товары» расчёт выполнялся с полным названием карточки. Для выбора издания это другое значение, поэтому цена исчезала и ручное обновление не помогало.

Название игры и Steam AppID теперь проходят через результат поиска/мониторинга в отслеживаемую карточку и постоянный кэш. Проверенная цена сохраняется до первого обновления, а повторные запросы используют тот же контекст игры. Для старых карточек контекст восстанавливается по однозначному совпадению с известными играми; неоднозначные наборы и части серии не подменяются догадкой. При сетевой ошибке последняя проверенная цена остаётся с явной отметкой отсутствия связи. Недоступность товара по-прежнему скрывает актуальную цену.

Регрессия: товар с выбором основной игры/дополнения и страны; стартовая цена 1 ₽, подтверждённая 4914 ₽, после обновления 5200 ₽, после перезапуска 5300 ₽. Дополнительно проверяются восстановление карточки 1.0.6 без повторного добавления и сохранение цены при HTTP 503.

versionCode 111, прежняя debug-подпись. Базовый APK проверки обновления — 1.0.6. Стабильный Release автоматически не публикуется.
