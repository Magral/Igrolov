# Игролов 1.1.6

- Исправлены отдельные публичные маршруты GGSEL для категорий и товаров; добавлен переход на основной host при DNS и HTTP 4xx ошибках.
- Если API каталога возвращает пустой список, точная категория ищется через публичный `/elastic/goods/query`.
- GGSEL category ID сверяется с точным названием и slug страницы, а предложения проходят проверки основной игры, Steam Gift/Key, региона, наличия и цены.
- Ручной поиск и мониторинг используют общий клиент GGSEL.
- Живой smoke test проверяет активную товарную строку с ID и подтверждённой ценой перед публикацией.
