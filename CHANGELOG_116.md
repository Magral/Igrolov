# Игролов 1.1.6

- Категория GGSEL выбирается по точному названию, а её `digi_catalog` берётся из данных страницы категории перед загрузкой предложений.
- Исправлены адреса публичного каталога GGSEL: поиск категорий и загрузка предложений используют действующие API-маршруты.
- GGSEL снова участвует в поиске цен и фоновом мониторинге; добавлена проверка живых маршрутов перед публикацией релиза.
- Добавлена живая проверка последовательности «точная категория → ID страницы → список товаров» перед публикацией.
- Сохранены строгая проверка основной игры, Steam Gift/Key, региона РФ, наличия и исключение DLC/аккаунтов.
