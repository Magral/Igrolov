# Игролов 1.6.1

## Исправление миниатюр
- Общий загрузчик портретных обложек используется в «Лидерах» (бестселлеры, новинки, скидки, фесты), «Желаниях», поиске и мониторинге.
- При сбое исходной обложки приложение получает актуальный URL библиотеки Steam, затем проверяет вертикальные постеры на открытой странице SteamGridDB и пробует резервные адреса Steam.
- Горизонтальные изображения не подставляются в вертикальные карточки.

## Обязательная проверка перед релизом
- GitHub Actions проверяет реальные изображения для бестселлеров, популярных новинок и игр активных тематических распродаж.
- Проверяется не только HTTP-ответ, но и тип/сигнатура изображения; если для любой проверяемой игры нет доступного вертикального постера, релиз блокируется.
