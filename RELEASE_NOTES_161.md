# Игролов 1.6.1

## Исправление миниатюр
- «Лидеры» получают актуальные вертикальные постеры из Steam по хешированным адресам, а не только по старым статическим URL.
- Если официальной обложки Steam нет, приложение ищет вертикальный постер на открытой странице SteamGridDB.
- Старые статические адреса остаются последним источником; горизонтальные изображения в вертикальные карточки не попадают.

## Проверка перед релизом
- GitHub Actions проверяет реальные URL постеров для текущих 100 бестселлеров и не публикует релиз, если хотя бы одна обложка недоступна.
