# Изменения в Игролове 1.5.7

- Удалена необходимость получать, хранить и вводить API-ключ SteamGridDB.
- Внешние вертикальные обложки загружаются с публичной страницы игры SteamGridDB по Steam App ID.
- Из разметки страницы выбираются только карточки с размером 600×900 и прямыми полноразмерными ссылками на CDN SteamGridDB.
- Добавлены проверки, что ссылка ведёт только на HTTPS CDN SteamGridDB и файл является допустимой статичной обложкой.
- Добавлено кэширование положительных и пустых результатов, чтобы не загружать страницу при каждом показе карточки.
- Горизонтальные изображения по-прежнему исключаются из портретных карточек, включая устаревшие адреса кэша.
- В настройках больше нет поля API-ключа; пояснение обновлено.
- Добавлены регрессионные тесты разбора публичной HTML-страницы и строгого фильтра портретных обложек.
