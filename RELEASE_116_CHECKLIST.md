# Игролов 1.1.6 — исправление поиска GGSEL

Статус: опубликован (`v1.1.6`).

- [x] Исправлены раздельные публичные маршруты поиска категории и товаров.
- [x] Каталог переключается на основной API host при DNS или HTTP 4xx ошибке.
- [x] Если список каталога пуст, запускается точный поиск через `/elastic/goods/query` по названию и найденной категории.
- [x] Общий клиент используется ручным поиском и фоновым мониторингом.
- [x] Добавлены регрессионные тесты точных маршрутов, HTTP 404, цены за единицу и неактивных товаров.
- [x] Unit-тесты, Debug APK и instrumentation APK прошли на релизном commit `ca7d5e3`.
- [x] UI-сценарии прошли на Android API 26 и 29 (API 26 после успешного перезапуска job).
- [x] Live smoke подтвердил активные товары Stellaris с ID, `is_active=true` и ценой за единицу на релизном commit `ca7d5e3`.
- [x] GitHub Release `v1.1.6` опубликован с `Igrolov-1.1.6.apk`: https://github.com/Magral/Igrolov/releases/tag/v1.1.6

Релиз блокируется, если GGSEL query endpoint не возвращает активную строку с ID и подтверждённой ценой, пригодную для парсера приложения.
