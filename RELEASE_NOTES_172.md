# Игролов 1.7.2

- Исправлен индикатор мониторинга: ожидание запуска или сети не считается активным обновлением, а после сохранения последнего результата анимация останавливается.
- Ручная и фоновая проверки больше не стартуют одновременно при добавлении игры. Очередная фоновая проверка планируется примерно через час.
- При обновлении цен используется уже выбранное издание: повторная загрузка его пакетов Steam больше не требуется.
- Plati завершает загрузку после короткой последней страницы, даже если сервер не прислал число страниц. Отмена проверяется перед каждой страницей и повтором запроса.
- При временных сбоях сохраняются подтверждённые цены и история.

Проверки: unit-тесты состояний мониторинга, сценарий Royal Edition → остановка → повторный запуск → завершение без индикатора на Android 26/29, проверка окончания пагинации и отмены каталога, существующие сценарии поиска и обновления приложения, живые проверки источников и обложек.
