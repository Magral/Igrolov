# Игролов 1.1.4 — интеграция GGSEL

Статус: проверки CI пройдены; ожидается публикация GitHub Release.

- [x] Подключён публичный покупательский API GGSEL без авторизации Seller API.
- [x] GGSEL ищется по точной категории Steam-игры и сохранённым алиасам.
- [x] Добавлены общая выдача, маркировка источника, ссылки на GGSEL и фильтр Plati/GGSEL.
- [x] Отклоняются DLC и товары с неизвестным составом, аккаунты/аренда, неподтверждённые Gift/Key, предзаказы, неактивные карточки и варианты без выбранной цены.
- [x] Цена читается для одной копии из RUB-поля покупательского каталога; регион РФ не выдумывается, статус явно помечается.
- [x] GGSEL-минимум не записывается в wishlist-поле Plati; GGSEL не передаётся в Plati-мониторинг.
- [x] Добавлены unit-тесты парсинга и фильтрации GGSEL-ответов.
- [x] Обновлены UI-регрессии для 1.1.4 и кнопки «Искать».
- [x] Поднята версия до 1.1.4 / versionCode 121.
- [x] Unit-тесты, APK, instrumentation APK прошли GitHub Actions.
- [x] UI-сценарии прошли на эмуляторах Android API 26 и 29.
- [ ] Стабильный GitHub Release опубликован с APK.
