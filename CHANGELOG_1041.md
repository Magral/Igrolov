# Игролов 1.0.4.1 — исправление ручного поиска

Обращение: поиск Stellaris в 1.0.4 показывал DLC, отсутствующие товары и использовал каталожную цену без подтверждения варианта.

- В фильтре «Игра» требуется положительное распознавание основной игры. Неизвестный суффикс названия больше не означает основную игру. DLC проверяются до показа, а не после длительной фоновой загрузки справочника.
- Быстрый Steam-справочник получает основную игру и ID её DLC одним запросом appdetails, без последовательной загрузки всех названий дополнений.
- Только is_available=1 и успешная загрузка карточки позволяют предложению попасть в ручную ценовую выдачу.
- Фиксированная цена берётся из актуального prices.default.RUB. Цена каталога не используется как запасной вариант при отсутствии свежей цены.
- РФ выбирается по label параметра, а не по техническому имени option_radio_*. Для однозначно выбранных РФ/основной игры вызывается Digiseller price/calc. Проверяются валюта RUB, количество 1, комиссия, положительная цена и результат API.
- Неподдержанные/скрытые варианты, неопределённый остаток отдельно выдаваемого варианта, свободная цена, внешняя проверка параметров и отсутствие расчёта исключают товар из ценовой выдачи.
- Объявленный выбор издания без данных вариантов API не превращает базовую цену в подтверждённую.
- Сортировка выполняется после обновления цен.
- Регрессия включает все 100 строк реальной страницы Stellaris с полными описаниями и параметрами, тесты наличия/цен/состава и поиск через интерфейс эмулятора.
- versionName=1.0.4.1, versionCode=108. Старая версия 1.0.4 не заменяется задним числом.

Мониторинг и PriceMonitor.kt не менялись. Ограничения: актуальность на момент запроса, возможные ошибки продавца и отличающиеся комиссии другого способа оплаты. Неоднозначные предложения могут отсутствовать в выдаче.
